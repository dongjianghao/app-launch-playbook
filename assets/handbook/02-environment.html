Stage 02 · Environment

先把“编译 → 安装 → 启动”跑通

鸿蒙开发没有热重载，改一次就要重新 build、签名、装包。真正省时间的方式，是把这些步骤脚本化， 再让日常调试固定在模拟器上。

PowerShell 环境变量

$env:JAVA_HOME='C:\Program Files\Huawei\DevEco Studio\jbr'
$env:PATH="C:\Program Files\Huawei\DevEco Studio\jbr\bin;C:\Program Files\Huawei\DevEco Studio\tools\node;$env:PATH"

三、设备策略

模拟器：日常开发默认用

APP_NAME固定使用 127.0.0.1:5555，Mate 90 Pro / HarmonyOS 7.0.0 / API 26，1280×2832。端口稳定，数据独立，可以随便清库造数据。

真机：只做最终验收

安全区、震动、拖拽手感、桌面卡片、通知、小艺手势这些只能在真机判断。无线调试会掉线，先 hdc list targets，必要时 tconn。

重要习惯

编译通过 ≠ 能跑；能跑 ≠ 体验对。安全区、震动、卡片、拖拽这些必须回真机验收。

四、常用命令

日常编译、安装、启动
cd YOUR_PROJECT_DIR\PROJECT_NAME
node 'C:\Program Files\Huawei\DevEco Studio\tools\hvigor\bin\hvigorw.js' --mode module -p product=default -p module=entry@default assembleHap --no-daemon

$hdc='C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc -t 127.0.0.1:5555 install -r 'YOUR_PROJECT_DIR\PROJECT_NAME\entry\build\default\outputs\default\entry-default-signed.hap'
& $hdc -t 127.0.0.1:5555 shell "aa start -a EntryAbility -b YOUR_BUNDLE_ID"
截图与模拟点击
# 截图
& $hdc -t 127.0.0.1:5555 shell "snapshot_display -f /data/local/tmp/a.jpeg"
& $hdc -t 127.0.0.1:5555 file recv /data/local/tmp/a.jpeg C:\path\to\a.jpeg

# 点击 / 滑动
& $hdc -t 127.0.0.1:5555 shell "uinput -T -c X Y"
& $hdc -t 127.0.0.1:5555 shell "uinput -T -m X1 Y1 X2 Y2"

# 按住不放，用于验证按下态
& $hdc -t 127.0.0.1:5555 shell "uinput -T -d X Y"
& $hdc -t 127.0.0.1:5555 shell "uinput -T -u X Y"
推荐封装脚本
pwsh -File YOUR_PROJECT_DIR\tools\build-install.ps1
pwsh -File YOUR_PROJECT_DIR\run-tests.ps1
pwsh -File YOUR_PROJECT_DIR\tools\build-release.ps1

六、Vibe Coding 提示词

1. 生成一键构建脚本
请为 HarmonyOS NEXT 工程写一个 PowerShell 脚本，名字叫 build-install.ps1。
要求：
1. 参数：-Device 默认 127.0.0.1:5555，-SkipBuild，-NoStart
2. 自动设置 DEVECO_SDK_HOME、JAVA_HOME、PATH
3. 用 hvigorw.js 编译 entry 模块主包
4. 判断 BUILD FAILED 或产物不存在时打印错误并退出码 1
5. 用 hdc 安装 -r
6. 安装成功后 aa start 启动
7. 所有关键步骤打印“ok”
工程路径 YOUR_PROJECT_DIR\PROJECT_NAME，bundle YOUR_BUNDLE_ID，DevEco 路径 C:\Program Files\Huawei\DevEco Studio。
2. 生成单元测试脚本
请为 HarmonyOS 的 Hypium 测试写一个 PowerShell 一键脚本 run-tests.ps1。
要求：
1. 编译 entry@ohosTest 的测试 HAP
2. 安装到 -Device 指定的设备
3. 用 aa test -b YOUR_BUNDLE_ID -m entry_test -s unittest OpenHarmonyTestRunner -s timeout 120000 运行
4. 从输出解析 OHOS_REPORT_RESULT 里的 Tests run / Failure / Error / Pass
5. 有失败时打印失败用例，并返回退出码 1；全部通过返回 0
6. 支持 -Class 只跑某一组用例
