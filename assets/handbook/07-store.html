素材不是最后补，截图要按真实设备尺寸做

图标、截图、宣传图、应用介绍、分类分级、隐私政策六类物料，每类都有明确尺寸和口径。 APP_NAME用脚本整套生成，避免手搓造成尺寸、状态栏、数据不一致。

三、分类与年龄分级

APP_NAME的结论

分类：工具 > 效率。年龄分级：3 周岁以上 / 全年龄。AGC 内容分级问卷八项全部选“无 / 否”。

分级属于应用信息，上架后随时可改，不需要重新打包；但每次改都要重新过审，且从高往低改会更细，尽量一次填准。

四、Vibe Coding 提示词

1. 生成应用图标
请为 HarmonyOS App【APP_NAME】生成商店图标所需素材。
主题：极简日历 + 三条班次色带。
要求：
1. 背景 background.png 和前景 foreground.png 分层
2. 生成 1024/512/216/144/72 五档方形满幅 PNG，不带圆角
3. 前景必须留出足够安全边距，避免被系统圆形/圆角裁切
4. 同时说明如何同步到 AppScope 和 entry 两处资源目录
5. 输出 Python/Pillow 脚本，而不是让我手动导出
2. 生成截图与宣传图脚本
请写一个 Python/Pillow 脚本，把 App 截图批量加工成上架素材。
输入：7 张原始截图，1280×2832
输出：
1. 7 张商店截图，裁边缩放到 1260×2844
2. 重绘状态栏：去掉通知图标，时间统一 9:41，深浅背景匹配
3. 7 张宣传图，1080×1920：手机框 + 主标题 + 副标题 + 三个卖点标签
要求：
- 状态栏右侧画信号、wifi、电量
- 截图底部裁掉手势条留白，但不要碰到 tabbar 文字
- 手机框圆角、阴影、前置摄像头小药丸都做出来
- 所有坐标参数集中可改
3. 写应用市场文案
请为【APP_NAME】写应用市场文案，用于华为 AGC。
产品：倒班排班日历 + 工时统计，HarmonyOS NEXT 原生，无广告，数据本地存储。
请输出：
1. 应用名称
2. 三句一句话简介（一句推荐，两句备选）
3. 应用详情介绍，按段落，纯文本，适合手机阅读
4. v1.0.0 更新说明
5. 搜索关键词
6. 建议分类与年龄分级
要求：不写“优化了用户体验”这种空话；卖点必须具体。
4. 生成隐私政策
请为【APP_NAME】写一份隐私政策，用于应用内原生页面和华为 AGC。
关键事实：
- 不注册账号，不收集、不上传任何个人信息
- 排班数据只保存在本机应用沙箱
- 应用不联网、无服务端、无第三方 SDK、无广告
- 只申请振动、日历读写权限
- 开启班次提醒后，把排班写入系统日历的“APP_NAME排班”本地账户
- 主体：YOUR_COMPANY，邮箱 YOUR_CONTACT_EMAIL
请包含：我们不收集的信息、仅本机保存的数据、不联网说明、权限说明、存储安全、未成年人、你的权利、政策更新、联系方式。
5. 隐私政策在 AGC 表单的填写口径
请把上面的APP_NAME隐私政策，转换成华为 AGC「生成协议工具」的逐项填写建议。
要求：
1. 明确哪些项不勾选、哪些项整段替换
2. 设备权限调用填振动、日历两项
3. 检查清单：全文不能出现网络请求、CDN、位置、通讯录、设备标识、第三方 SDK
4. 最终口径与应用内 Privacy.ets、官网 privacy.html 一致
