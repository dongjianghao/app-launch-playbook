首页 / 08 资质与备案

Stage 08 · Qualification & Filing

备案是真正的主线卡点，越早启动越好

资质和备案不依赖代码，但耗时最长、最不可控。APP_NAME的经验是：企业实名、域名、服务器、网站备案、App 备案、 公安联网备案、发布证书与签名，全部并行推进，并且所有关键结论都写进文档。

一、总流程

  1. 准备企业主体：营业执照、企业实名。
  2. 注册 / 认证华为开发者账号，并完成企业资质审核。
  3. 购买域名并实名，准备服务器（如阿里云轻量）。
  4. 先办网站 ICP 备案（在哪里买服务器，就在哪里提交）。
  5. 网站备案下号后，基于同一主体补填 App 备案信息。
  6. 拿到 App 备案号后，填进 AGC 上架表单和 App 内 icp_number。
  7. 网站可访问后，30 天内完成公安联网备案。
  8. 在 AGC 创建发布证书 + 发布 Profile，出正式签名 .app。

三、发布签名

发布证书 + Profile 已就绪后

密钥库 .p12 和口令必须备份两处，丢失就无法更新已上架应用。口令确认存好后，删掉同目录的明文口令文件。

签名配置两个坑

口令由 DevEco 加密存储，不要手写进 build-profile.json5；certpath 要指向 AGC 下载的根 CA 文件（证书链），不是叶子应用证书。

备案公钥必须与实际发布包一致

用 release 证书，不用 debug；以后换发布证书要办变更备案。

六、Vibe Coding 提示词

1. 整理上架备案清单
我要把一个 HarmonyOS 原生 App【APP_NAME】上架到华为应用市场。
请帮我整理一份《上架准备清单》，按“必须先定 → 要做的开发 → 要准备的素材 → 已验证无需改动 → 上线后做”排列。
背景：
- 企业主体已实名
- 无服务端，数据全部本地
- 节假日数据纯本地，不联网
- 服务器是阿里云轻量，网站备案和 App 备案都在阿里云办
- 应用包名 YOUR_BUNDLE_ID
请特别写清：网站备案、App 备案、公安备案、发布证书、签名、版权信息、内容分级。
2. 整理开放能力申请材料
请为 HarmonyOS App【APP_NAME】写一份 AGC 开放能力申请说明。
能力：【实况窗 Live View Kit】或【代理提醒】。
产品背景：排班日历，倒班人群，数据全本地，无账号、无服务端。
请包含：申请信息表、场景说明、展示内容、触发与生命周期、用户价值、隐私数据说明、常见被问到的点。
要求：语言像正式申请材料，可直接粘贴；如果该能力不适合我的场景，先明确说明原因。
3. 写服务器部署脚本
请为我的静态官网写两个服务器脚本：
1. deploy_site.sh：安装 nginx/git，拉取官网代码，写 nginx 配置，重启并自测
2. nginx_setup.sh：修正 YOUR_WEB_ROOT 权限，重写 nginx 配置，测试首页和静态资源
要求：
- 静态站，root YOUR_WEB_ROOT
- server_name 同时支持域名和 IP
- 静态资源缓存 30 天
- 用 sudo，适合 Ubuntu 24.04
- 输出 HTTP 状态码验证
4. 生成 release 构建脚本
请为 HarmonyOS 工程写 build-release.ps1。
要求：
1. 设置 DevEco 环境变量
2. 用 hvigorw.js --mode project -p product=release -p buildMode=release assembleApp 编译
3. 产物路径 build\outputs\release\PROJECT_NAME-release-signed.app
4. BUILD FAILED 或产物不存在时打印错误，退出码 1
5. 成功后打印产物完整路径、大小、构建时间
注意：签名口令由 DevEco 加密存储，脚本里不要写任何口令。
