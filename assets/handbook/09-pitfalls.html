Stage 09 · Pitfalls

踩过的坑，按“现象 → 原因 → 解法”存档

这些坑大多不是 API 不会用，而是平台机制和直觉不一致。建议开发前快速读一遍，开发中遇到再展开查。 第 15、16 条来自实况窗，虽然 v1 已移除，但作为 Live View Kit 平台知识保留。

ArkUI 渲染与组件

1. ArkUI 局部更新：模块级可变数据不会触发刷新

现象手动标记后角标不出现，重启才正确。

原因ArkUI 只重算表达式读过的可观察状态；普通 Map 变化框架看不见。

解法加 @State 版本号，变化时 +1；让取数方法先读它。UI 直接读模块级可变数据是反模式。

2. LazyForEach 不会因为 @State 变化重建已有子节点

现象月历切换班次类型后，已渲染格子不更新。

原因LazyForEach 缓存已生成子节点。

解法给数据源加 notifyReload()，配置变化时显式通知。

3. Grid 的拖拽回调在该 SDK 版本下不触发

现象三列拖拽排序，点击正常，onItemDragStart 不进。

原因SDK 版本下 Grid 拖拽回调未触发。

解法改用 List + .lanes(3, 10)。

4. 多列 List 的 onItemDragMove 给的 index 不可靠

现象拖拽目标位置错位。

原因跨列时会返回非整数坐标。

解法自己用指针坐标除以单元尺寸求行列。

5. parallelGesture(LongPressGesture) 会抢走长按拖拽

现象加长按震动后拖拽失效。

原因手势和拖拽竞争。

解法在 onTouch 里自起 460ms 定时器触发震动，抬起或移动超阈值取消；震动改 15ms。

6. @Builder 传基本类型参数不会刷新

解法内联展开，或让 builder 读组件 @State，不接基本类型参数。

7. outline 与 .animation() 的顺序会影响圆角

现象描边元素从无到有时圆角从 0 动画到 14。

解法outline 必须写在 .animation() 之后。

8. Image 默认参与系统拖拽，长按图标触发小艺

解法所有装饰性图标统一加 .enableAnalyzer(false).draggable(false)。

9. 固定宽高 + padding 是“内减”的

现象16×16 图标加左右各 10 padding 被压没。

解法扩大热区要把整体尺寸一起加大，例如 width(34).height(34).padding(9)。

卡片 / 实况窗

10. 卡片跟随系统深浅色，就不能自己算颜色传给它

现象深色系统下卡片仍白。

原因卡片颜色由数据覆盖了框架自动适配。

解法中性色用 resources/base 与 resources/dark 两套资源；只把用户自定义班次颜色走数据。

11. 2×2 卡片比想象中窄得多

解法2×2 实际只有 130~160vp 宽，两种尺寸各写一套布局，长文本 maxLines(1) + 省略。

12. 调试签名拿不到通知配额

现象发布提醒报 1700002，一条都发不出去。

解法代码和参数验证正确，换正式签名后再实测。

13. 重新安装 HAP 会回收桌面卡片

现象开发期每次装包，桌面卡片消失。

解法开发期正常，重新添加；应用内提供“添加桌面卡片”入口。

15. 实况窗换图标，胶囊里还是旧图

现象文案刷新、图标不变。

原因系统按资源缓存图片，已创建实况窗不会重新读盘。

解法换图标要重建实况窗；图标按圆形裁切设计。

16. primary.content 富文本数组会直接拼接

现象两段文本显示成“08:00 - 20:0040%”。

解法分隔符自己写进文本；RichText 的 textColor 在所有对象中必须一致。

持久化与提醒

14. 没注册过的 PersistentStorage 键，冷启动后为空

现象改成规则列表后，冷启动把已有规则清空。

原因新键没 persistProp 注册，读到 undefined 误判首次运行。

解法读取函数第一件事注册所有相关键，再判断。

17. 这个项目“落盘”只认 preferences

现象用 AppStorage.setOrCreate 保存设置，重启回到默认。

解法新增任何“要记住”的设置，先问它到底写进 preferences 没有；load/save 成对。

18. PersistentStorage 镜像不可靠：进程被杀后为空，启动流程覆盖磁盘

现象冷启动后用户排班全部消失。

原因镜像写盘延迟，强杀丢镜像；启动把空镜像写回 preferences。

解法启动时 hydrateMirrorFromDisk，镜像空但磁盘有数据时用磁盘补镜像，绝不写磁盘；手动标记也补 preferences 副本。

19. 日历提醒会被“日历应用的通知权限”拦掉

现象日志已触发，但显示 Not allow to notify[com.huawei.hmos.calendar]。

原因提醒由日历应用发通知，日历通知被关则静默失败。

解法UI 提示“需开启日历的通知权限”；以后可申请代理提醒由APP_NAME自己发。
